# Accessibility Repository Audit

## Project Structure

- `client/` – frontend application boundary
- `server/` – backend/API application boundary
- `docs/` – architecture and audit documentation
- `test/` – test and accessibility verification
- `accessibility-audit.csv` – audit findings and evidence

## Audit

The audit covers a public-facing Airbnb page using Lighthouse and keyboard-only navigation.

See `accessibility-audit.csv` for the documented findings.
